# PromptForge - AI 绘图资料与工作流管理工具

个人使用的 Electron 桌面项目：围绕绘图资料分散、提示词难复用、生成测试与结果记录脱节的问题，组织检索、收藏、组合、测试和归档流程。

本仓库于 2026-10-16 同步经过筛选的开发源码快照。它不是稳定版安装包，也没有对外用户量、商业收入或已测量的提效比例。

## 个人职责与 AI 分工

- 本人负责需求梳理、资料组织、功能取舍和实际操作测试。
- 代码实现与问题排查借助 AI 编程工具完成；不将其描述为脱离 AI 独立完成的传统全栈研发。
- 模型、第三方库和外部 API 的能力属于各自提供方。资料条数不等于原创作品数或产品用户数。

## 源码模块

- 图库与详情：图片和元数据组织、检索、筛选与查看。
- 提示词与公共库：提示词组合、收藏、导入及预设管理。
- 工作流与测试：ComfyUI 工作流组织、测试任务与结果记录。
- LLM 辅助：提示词分析、资料处理与模型连接配置。

上述为源码覆盖范围，具体可用性取决于本地依赖、外部服务和配置；不承诺全部远程环境均可直接使用。

## 技术结构

| 部分 | 使用技术 |
| --- | --- |
| 桌面与主进程 | Electron、TypeScript |
| 页面 | React、Vite、CSS Modules |
| 本地存储 | SQLite / better-sqlite3 |
| 外部工具 | 可配置的 LLM 与 ComfyUI 服务 |

```text
src/main/       主进程与服务
src/preload/    桌面桥接
src/renderer/   页面与交互
docs/           需求、架构与开发记录
tests/          测试材料
```

`docs/ui-prototypes/` 与 `UI原型/` 中的图片是早期设计原型，不是当前版本运行效果或真实用户数据证明。

## 本地开发

```bash
npm ci
npm run dev
npm run typecheck
```

`npm run build` 会重新生成构建目录，`npm run pack:win` 用于 Windows 打包。请在自己的环境中核实 Node/Electron 与原生 SQLite 依赖的兼容性；本次上传未重新安装依赖或打包发行。
