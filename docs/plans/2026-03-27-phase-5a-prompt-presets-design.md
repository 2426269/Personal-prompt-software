# PromptForge · Phase 5A 设计记录

日期：2026-03-27

## 目标

- `收藏` 页回归真实收藏页，只显示 `entries.is_favorited = 1` 的条目。
- `提示词集` 页彻底改成“提示词预设库”，不再承担收藏/标签云职责。
- 预设来源严格限定为“当前图片的 LLM 分析结果”，不回退旧的整条目分析语义。

## 方案

### 1. 收藏页

- 在 `EntryListParams` 增加 `favoritesOnly`，由 `EntriesRepository.list()` 直接下沉到 SQLite 条件 `e.is_favorited = 1`。
- `Favorites` 页只请求收藏结果，并在前端基于这些结果做搜索与用户标签筛选。
- 保留“标签筛选”能力，但标签来源改为“收藏结果里实际出现的用户标签”，避免再出现全库混入。

### 2. 提示词预设数据结构

- 新增表 `prompt_presets`，字段包含：
  - 预设名
  - 来源条目 / 来源分析 / 来源图片索引
  - 来源条目标题与类型
  - 参考图路径
  - 默认语法模式
  - 正向分类 JSON
  - 负向分类 JSON
  - 正负向条目数
- 预设内保留分类层级，条目保留：
  - `text`
  - `weight`
  - `note`
  - 稳定 `id`

### 3. 导出链路

- 导出入口放在详情页 `LLM 分析结果` 卡片。
- 仅当当前图片已有分析结果时允许导出。
- 导出弹层从 `analysis.categories + analysis.customCategories` 生成可编辑草稿：
  - 分类级勾选
  - 全选 / 全部排除
  - 单条勾选
  - 词条文本编辑
  - 权重编辑
  - `note` 保留与编辑
- 负向分类识别规则：
  - `key/label` 命中 `negative / 负向 / 反向`

### 4. 预设库页面

- 左侧：预设列表与搜索。
- 右侧：预设详情。
- 详情展示：
  - 预设名称
  - 正向完整导出文本
  - 负向完整导出文本
  - 分类明细与 `note`
  - 参考图
  - 返回来源详情

### 5. 权重语法切换

- `ComfyUI / SD`：
  - 普通加权输出为 `(tag:1.2)`
- `NAI`：
  - 使用 `{}` / `[]` 近似映射权重
  - LoRA 标签保持 `<lora:name:weight>` 形式
- 导出时选择默认模式，详情页内可随时切换重新渲染。

## 边界

- 不修改当前 LLM 运行时 payload。
- 不重新发送完整 `raw_json` 给模型。
- 不把 `removed_specific` 自动塞进预设。
